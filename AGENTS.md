# AGENTS.md — Lakshmix Project Architecture

## Overview

A TanStack Start (React SSR) application deployed on Netlify free tier. No database or backend functions — purely frontend/SSR rendered pages. Routes are file-based under `src/routes/`.

## Key Directories

```
src/
  data/
    characters.ts     — All character data, profiles, qualities, wish messages, YouTube IDs
  routes/
    __root.tsx        — HTML shell (head, body, fonts)
    index.tsx         — Profile selection page ("Who's Watching?")
    home.tsx          — Main Netflix-style home page
    locked.tsx        — Non-Lakshmi profile locked page (humorous)
    character/
      $id.tsx         — Dynamic character detail page (uses character ID from URL)
  styles.css          — All custom CSS (Netflix-inspired design system + Tailwind)
  router.tsx          — Router instance creation (route tree auto-generated by plugin)
```

## Design System

CSS custom properties in `styles.css`:
- `--lx-red`: #E50914 (Netflix red equivalent)
- `--lx-bg`: #141414 (dark background)
- `--font-display`: Bebas Neue (big titles)
- `--font-serif`: Cormorant Garamond (cinematic paragraphs)
- `--font-body`: Inter (UI elements)

## Routing

Routes are auto-discovered by `@tanstack/router-plugin`. The plugin generates `src/routeTree.gen.ts` at build time. Never edit `routeTree.gen.ts` manually.

## Adding Content

### New character
1. Add entry to `characters` array in `src/data/characters.ts`
2. Add `cardColors` entry in both `src/routes/home.tsx` and `src/routes/character/$id.tsx`

### Replacing YouTube videos
Update `youtubeId` field in `src/data/characters.ts` with the YouTube video ID.

### Adding real images
Replace `char-card-bg` gradient backgrounds with `background-image: url(...)` in the route files.

## Conventions

- No comments unless absolutely non-obvious
- CSS-only animations where possible (transform/opacity only)
- All cinematic text uses `font-family: var(--font-serif)` with `font-style: italic`
- Netflix-style card hover: `transform: scale(1.08) translateY(-8px)`
- YouTube embeds use `?rel=0&modestbranding=1` parameters
